# Glossary

- Q&A: Luồng hỏi đáp pháp lý qua AI.
- ShareText: Nội dung chia sẻ mạng xã hội tạo từ câu trả lời.
- Admin Customers Gate: Lớp bảo mật bổ sung cho `/admin/customers`.
- TOTP: Mã 2FA dạng time-based (Google Authenticator).
- Supabase Local: Supabase chạy bằng Docker trên máy dev.
- Graph API: Facebook Graph API cho automation.
